# todo_cli

A command-line todo application built in C. This is a basic project for the purpose of learning basic C programming

## Installation

```bash
git clone https://github.com/yourusername/todo_cli.git
cd todo_cli
make
```

## Usage

```bash
./todo [command] [args]
```

## Commands

- `add <task>` - Add a new todo
- `list` - Show all todos
- `delete <id>` - Delete a todo
- `complete <id>` - Mark todo as complete
- `uncomplete <id>` - Mark todo as uncomplete
